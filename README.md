# Śāstras

An explorable map of Indian philosophy and the classical sciences. It's Sanskrit first,
with English glosses on tap, and every claim is sourced. It will live at `sastras.dhanjit.me`
(not deployed yet).

Design: [docs/superpowers/specs/2026-10-12-sastras-site-design.md](docs/superpowers/specs/2026-10-12-sastras-site-design.md) · Writing rules: [docs/writing-rules.md](docs/writing-rules.md) · Working in the repo: [CLAUDE.md](CLAUDE.md)

Corrections welcome: use the "Suggest a correction" link on any page, or open an issue.

Map structure from the study map by Prathosh A. P. (lecture: Navigating Indian Śāstras, https://youtu.be/hj6yzj_HlvA)
